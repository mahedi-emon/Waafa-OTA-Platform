# Design direction (refined in A1: docs/design/DESIGN.md, MOTION.md, COMPETITOR_BENCHMARK.md)
- Premium, calm, confident. Deep navy -> electric blue from the logo; ribbon gradient 120deg #020D39 -> #003FBE ->
  #0D8CEE -> #39CCE9; gold #A8782F rare (triangle marker for Best seller/Featured, never small text on white).
- Type: Plus Jakarta Sans (display 600-800) + Inter (body 400-800); Hind Siliguri for Bangla in P1.
- Signature elements: the ribbon (hero underlay, dividers, active-tab pill, loader), the gold triangle, the glass search
  card (only glass surface). Real photos with one cool grade; no AI/drawn images; lucide icons.
- Light-only public site at launch; admin dark mode is P1. Breakpoints 390 first, then 768, 1024, 1280, 1440.
- Motion: UI 150-300 ms, entrances 400-700 ms, springs for tabs (500/38) and sheets (380/34), 40-60 ms stagger,
  reveals once, parallax only in hero, success check draws itself, skeleton shimmer 1.4 s; reduced motion = 150 ms fade.
- Copy: plain, specific, sentence case; no emoji, no fake stats, no invented reviews, no "elevate/seamless/unleash/discover".
- Skills reconciled: PRD wins over taste-skill defaults (Inter, lucide, light-only are mandated).
