# When a task is done
1. In apps/web: `npm run build` (must pass), `npx tsc --noEmit`, `npm run lint`.
2. Check the changed screen at 390, 320, 768 and 1440 px (Playwright MCP) and with reduced motion.
3. Check keyboard use / focus rings for any interactive element.
4. Re-read CLAUDE.md "Never" list against new copy, data and images.
